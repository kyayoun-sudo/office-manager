# Modèle de design (référence)

Modèle d'interface d'administration (Nuxt 3 + shadcn-vue + Tailwind), gardé **comme référence visuelle** pour le nouveau
design d'Office Manager (`docs/PROMPT_CODEX_DESIGN_SHADCN.md`). Il ne fait pas partie de l'application : rien n'y est
exécuté, construit ni déployé.

Ce qui sert de référence : `app/assets/css/tailwind.css` (couleurs et rayons), `app/layouts/default.vue` (menu latéral,
en-tête, fil d'Ariane), `app/components/ui/` (composants), `app/assets/images/preview.png` (aperçu).

Nom, logo, icônes, adresses et identifiants du projet d'origine ont été retirés (16 novembre 2026).
