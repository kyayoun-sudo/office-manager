Entraîner les agents

Comment faire

  1. Dans « + Nouvelle mission », créez votre mission (nom + client suffisent).
  2. Déposez les pièces dans « Pièces reçues » : l'agent lit chacune, dit ce qu'elle est et la renomme.
  3. Ouvrez un test dans « Mes tests » : l'agent prépare le working file feuille par feuille, en pointillés.
  4. Corrigez l'agent à chaque fois qu'il se trompe : « C'est autre chose… » sur une pièce, « Pas juste ? Dites-le » sur une feuille, ou la case ci-dessous pour tout le reste. Dites ce qui manque et pourquoi.
  5. Quand c'est juste, « Oui, remplis ». Recommencez avec une autre mission : l'agent doit faire mieux.

Vos corrections sont envoyées au cabinet qui entraîne les agents ; une fois validées, tous les agents les appliquent. Elles ne contiennent pas les documents de vos missions : seulement ce que l'agent proposait et ce que vous avez dit.
