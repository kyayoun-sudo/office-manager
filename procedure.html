Exécuter le test dans le working file

L’Enhanced Auditor prépare l’étape selon le SOP courant et les pièces lisibles. Relisez les faits sourcés et les questions, puis inscrivez la préparation dans le working file. Les opérations chiffrées disponibles produisent leur résultat dans une feuille séparée.

Ce que demande ce test

Documents nécessaires

Déposez chaque document dans sa case (il va dans « Pièces reçues » de la mission, puis les agents le lisent). Pour ceux qui manquent, préparez la demande au client : elle part après validation par un manager.

Dépôt : 100 Mo maximum par fichier. Lecture PDF : jusqu’à 100 Mo, avec indication des pages réellement lues. Autres formats : 8 Mo.
