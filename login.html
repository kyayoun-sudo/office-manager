Connexion

Vous restez connecté sur cet ordinateur jusqu'à ce que vous cliquiez sur « Se déconnecter ». Mot de passe oublié : demandez au propriétaire du cabinet de le réinitialiser.

Solution provisoire, tant que les comptes ne sont pas créés : le même code que l'ancienne console pilote.

Tapez un code : l'application vous dit si c'est le code d'accès, le code propriétaire, ou aucun des deux, et ce qui manque sur le serveur. Aucun secret n'est affiché.
