Test du cabinet

Toute l'application testée sur une copie du cabinet : copie à l'identique du Drive, 5 missions d'audit sur 3 mois en accéléré (1 semaine = 1 jour), une équipe fictive dont les e-mails sont vos boîtes, et vous dans le rôle du CFO des clients. Fonctionne uniquement dans l'aperçu (preview) : le vrai cabinet n'est jamais touché.

Réservé au propriétaireConnectez-vous avec le compte propriétaire du cabinet de test.

1. Environnement de test

Chaque ligne doit être verte avant de commencer. Elles se règlent dans Vercel, variables de l'environnement Preview.

2. Copie du Drive

Tout le Drive du cabinet est copié dans le Drive partagé de test, sauf la mémoire de l'Orpailleur et les dossiers d'entraînement. Le vrai Drive est seulement lu.

Éléments non copiés ou en échec

3. Les fichiers du cabinet utilisés par les agents

Après la copie, chaque réglage doit pointer vers la copie, jamais vers le vrai fichier. Pour une ligne orange : dans Vercel (Preview), mettez la variable indiquée à l'identifiant de la copie, puis redéployez l'aperçu. Quoi qu'il arrive, le code refuse toute écriture hors du Drive de test.

4. Vos boîtes mail et l'équipe

Chaque rôle reçoit les e-mails de l'agent dans une de vos boîtes. Une même boîte peut tenir plusieurs rôles. Les adresses doivent figurer dans les listes du verrou mail (Vercel : AGENT_MAIL_SANDBOX_COLLEAGUES pour l'équipe, AGENT_MAIL_SANDBOX_CLIENTS pour le CFO).
