Le panneau Office Manager dans Excel

Les fichiers de travail s'ouvrent comme aujourd'hui depuis Google Drive sur l'ordinateur. Le panneau ajoute dans Excel : la revue par l'Enhanced Auditor écrite dans le fichier, les questions aux agents sur la sélection, le temps de travail par mission pour les indicateurs, et la fermeture propre d'un fichier oublié ouvert (après votre accord dans l'application).

1. Télécharger le fichier d'installation

Il est préparé pour l'adresse de cette application : .

2. L'installer pour tout le cabinet (une fois)

  1. Centre d'administration Microsoft 365 → Paramètres → Applications intégrées → Charger des applications personnalisées.
  2. Choisir « Fournir le fichier manifeste » et donner le fichier téléchargé.
  3. Choisir qui le reçoit (tout le cabinet ou un groupe), puis valider. Le bouton « Office Manager » apparaît dans l'onglet Accueil d'Excel (le délai de diffusion peut aller jusqu'à 24 heures).

Pour un essai sur un seul ordinateur, sans l'administration : Excel → Insertion → Compléments → Mes compléments → Charger mon complément → choisir le fichier.

3. À faire une fois dans Supabase

Créer les deux tables du panneau avec le script db/workfiles.sql (éditeur SQL de Supabase). Sans elles, le panneau s'ouvre mais ne peut ni enregistrer le temps ni garder les remarques.

Ce qu'il faut dire à l'équipe

  • Le panneau mesure le temps de travail actif sur chaque fichier de travail, pour suivre le budget des missions et les fichiers qui n'avancent plus. Ce n'est pas une surveillance minute par minute ; chacun voit son propre temps.
  • Un fichier laissé ouvert sans activité pendant 3 heures est signalé à son utilisateur, qui décide dans l'application s'il faut l'enregistrer et le fermer.
  • Les agents n'écrivent jamais dans les chiffres : seulement la feuille « Revue IA » et des commentaires.
  • Cocher « Ouvrir ce panneau avec ce fichier » dans le panneau l'ouvre automatiquement pour ce classeur.
